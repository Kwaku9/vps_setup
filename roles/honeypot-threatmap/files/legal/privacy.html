Privacy Policy

AICORTEX Backup · last updated 26 August 2026

AICORTEX Backup is a private, single-operator tool that copies encrypted backup archives from a personally owned server to the operator's own Google Drive. It is not a commercial service, has no other users, and no third party can sign in to it.

What the application accesses

The application requests one Google OAuth scope, https://www.googleapis.com/auth/drive.file. This scope grants access only to files the application itself creates. It cannot read, modify, list or delete any pre-existing file in the Drive account, and it is used solely to upload backup archives and to delete archives it previously uploaded once they pass a retention age.

What data is uploaded

Uploaded archives contain the operator's own server data: application databases, configuration and logs. The archives are encrypted on the server before transmission, using client-side encryption with keys held only by the operator. Google receives ciphertext and cannot read the contents. No data belonging to any other person is collected, processed or uploaded.

How credentials are stored

The OAuth refresh token is stored encrypted at rest on the operator's server and is never transmitted to any third party. It is used only to obtain access tokens from Google for the uploads described above.

Sharing and retention

No data is sold, shared, or disclosed to anyone. Nothing is transmitted to any third party other than Google Drive, which acts purely as the storage destination. Archives are retained on Drive for a fixed rolling window and then deleted automatically by the application.

Revoking access

Access may be withdrawn at any time from the Google Account permissions page at myaccount.google.com/permissions. Revoking access immediately and permanently ends the application's ability to reach the Drive account.
