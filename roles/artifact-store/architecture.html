Flow

    Rules the design holds to

    • Bytes live in a dedicated R2 bucket with bucket-scoped tokens. Nothing artifact-related listens on the VPS, and the VPS disk holds only the index.
    • File bytes never pass through a model. The agent hashes and uploads in its own shell; the server only issues a short-lived URL.
    • Write and read are separate servers with separate database roles, so a poisoned search result cannot reach a save credential.
    • Credentials come from the vault into a root-only env file, never a command line or a transcript.
    • The rclone mount is read-only and optional. Writes only ever go through the save path.
    • Originals are quarantined after a verified copy, never deleted on inference.
    • Every check ships with a control that must fail.
